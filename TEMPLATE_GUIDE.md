# README Template Guide

## Purpose
This repository provides a standardized README template designed to:
- Minimize time-to-first-success for users
- Clearly explain functionality and configuration
- Encourage contributions and clear ownership

## How to Use
1. Click **Use this template** on GitHub
2. Name your new repository
3. Replace all placeholder text in README.md
4. Delete this guide if you don't need it

## Required Sections
- Project Name
- Overview
- Quick Start
- Support / Contact

## Best Practices
- Keep Quick Start tested and minimal
- Prefer examples over explanations
- Update the README whenever onboarding breaks
